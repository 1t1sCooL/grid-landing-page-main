# Front-end Style Guide

## Layout

The designs were created to the following widths:

- Mobile: 375px
- Desktop: 1440px

> 💡 These are just the design sizes. Ensure content is responsive and meets WCAG requirements by testing the full range of screen sizes from 320px to large screens.

## Colors

- White: hsl(0, 0%, 100%)

- Blue 200: hsl(224, 100%, 95%)
- Blue 400: hsl(220, 100%, 64%)
- Blue 600: hsl(228, 100%, 60%)
- Blue 700: hsl(228, 99%, 58%)

- Black: hsl(0, 0%, 0%) — used at 25% opacity for the menu overlay

## Typography

### Body Copy

- Font size (paragraph): 17px
- Font size (stat descriptions, nav, footer): 14px

### Font

- Family: [Inter](https://fonts.google.com/specimen/Inter)
- Weights: 400, 500
